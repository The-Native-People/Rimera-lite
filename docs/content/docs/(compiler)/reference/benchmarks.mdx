These numbers are development-machine baselines, not a blanket performance
claim. They compare an already-built Rimera release executable against CPython
3.12 on a small fixture using integer arithmetic, loops, function calls,
collections, branches, and basic user classes.

<Cards>
  <Card title="Startup" description="Rimera: 1.704 ms median · CPython 3.12: 16.215 ms median." />
  <Card title="Startup result" description="The measured hello-world executable starts about 9.5× faster than CPython." />
  <Card title="Execution" description="Rimera: 13.269 s median · CPython 3.12: 0.086 s median on the current runtime fixture." />
  <Card title="Execution result" description="Generic execution is currently about 153× slower than CPython on this workload." />
</Cards>

<Callout title="Read this honestly">
  Native compilation already helps startup. General Python execution is still a
  major optimization target, so use these numbers as a baseline rather than a
  promise for your workload.
</Callout>

## What Rimera is optimizing next
