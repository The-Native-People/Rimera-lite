## Introduction

Rimera Lite <span className="text-fd-muted-foreground text-sm">(rim-era)</span>
compiles supported Python programs into standalone native executables. Use it
like a compiler: point `rimlite` at a Python entry file, choose an output when
you need one, and run the result.

### Terms

**`rimlite`:** The Rimera command-line program.

**Native executable:** The program produced by Rimera, ready to run without a
Python installation for the supported application.

**`.rimera/`:** A project-local cache for native build intermediates and debug
artifacts.

<Callout title="Before you compile">
  Rimera supports a substantial subset of Python, not every Python package or
  language feature. Check [Supported Python](/docs/reference/supported-python) before
  moving an existing project over.
</Callout>

## Run Rimera

The examples assume the `rimlite` binary is available on your `PATH`:

```bash
rimlite --help
rimlite tests/fixtures/basic/core.py --output dist/core
./dist/core
```

For a temporary compile-and-run:

```bash
rimlite tests/fixtures/basic/core.py --run
```

## Project principles

- Native code is emitted directly; Rimera does not generate C or run Python bytecode.
- Unsupported behavior fails with a stable diagnostic before an artifact is written.
- Supported language behavior stays clearly documented for users.
