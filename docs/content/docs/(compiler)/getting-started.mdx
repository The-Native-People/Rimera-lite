The `rimlite` binary is the normal user-facing entry point. Start by checking
the available commands:

```bash
rimlite --help
```

Compile a Python entry point to a native executable:

```bash
rimlite tests/fixtures/basic/core.py --output dist/core
./dist/core
```

Or compile and run it in one command:

```bash
rimlite tests/fixtures/basic/core.py --run
```

Use `--debug` for a readable native IR dump and compiler trace. Native
intermediates are cached in the project-local `.rimera/` directory.

## Common commands

<Accordions>
  <Accordion id="output" title="How do I choose the executable path?">

    Pass `--output` followed by the desired path:

    ```bash
    rimlite app.py --output dist/app
    ```

  </Accordion>
  <Accordion id="run" title="How do I run without keeping an executable?">

    Add `--run`. Rimera writes the temporary executable under `.rimera/bin/`:

    ```bash
    rimlite app.py --run
    ```

  </Accordion>
  <Accordion id="debug" title="How do I inspect a build?">

    Add `--debug` to emit a readable native IR file under `.rimera/ir/`:

    ```bash
    rimlite app.py --output dist/app --debug
    ```

  </Accordion>
</Accordions>

## Project configuration

Rimera also reads a `[tool.rimera]` table from `pyproject.toml`:

```toml
[tool.rimera]
output = "dist/app"
profile = "release"
run = false
```

See [Configuration](/docs/using-rimera/configuration) for the complete list of options.
